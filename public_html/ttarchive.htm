Club Time Trials - Rider Archive

This link will open a Google Spreadsheet showing riders' results going back to 2015. To display an individual rider's results the data will need to be filtered as follows:

  • Wait for the sheet to load
  • Locate the Filter View button which is adjacent to the (blue) View Only button
  • Select the Filter View button and from the drop-down select Create New Temporary Filter View
  • Click on the arrow that appears to the right of the Name in cell A1
  • In the dialog box go to Filter by Values and select Clear
  • This action will de-select the rider names
  • From the list select the name of the rider you wish to view
  • When you are done, simply close the spreadsheet
